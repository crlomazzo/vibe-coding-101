# Vibe Coding 101

A modern web application designed to introduce Operations professionals to the world of coding. This project provides a comprehensive guide to "vibe coding" - a practical approach to coding that focuses on real-world applications in Operations roles.

## Features

- 🎯 Clear navigation between different sections
- 📚 Comprehensive resources and examples
- 🎨 Modern, responsive design
- ✨ Smooth animations and transitions
- 📱 Mobile-friendly interface

## Sections

1. **What is Vibe Coding?**
   - Introduction to the concept
   - Key principles
   - Benefits for Operations professionals

2. **Blockers to Getting Started**
   - Common challenges
   - Solutions and strategies
   - Tips for success

3. **Examples**
   - SQL examples
   - Presentation creation
   - Feedback and insights gathering
   - Quality control
   - Thought partner applications

4. **How to Get Started**
   - AI Models (GPT, Anthropic, etc.)
   - Development tools
   - Visual creation tools
   - Data & collaboration tools
   - Integration tools

5. **Library of Vibe Coding Examples**
   - Video tutorials
   - Document resources
   - Real-world examples

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm (v7 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/vibe-coding-101.git
   cd vibe-coding-101
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

To create a production build:

```bash
npm run build
```

The built files will be in the `dist` directory.
